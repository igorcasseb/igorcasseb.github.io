Política de Privacidade

Última atualização: 20 de outubro de 2026.

Esta política vale para a ferramenta canais-igor, usada só pelo dono dos canais Mundo do GTA 6 e Descobrindo Nossa História no YouTube.

Quais dados a ferramenta acessa

Com a autorização do dono da conta Google, a ferramenta usa a YouTube Data API v3 para:

  • enviar vídeos para os canais do próprio dono (youtube.upload);
  • ler o nome e o identificador do canal conectado, para conferir que o vídeo vai para o canal certo (youtube.readonly).

A ferramenta não lê e-mails, contatos, comentários, dados de espectadores nem dados de outras pessoas.

Como os dados são guardados

O token de acesso fica salvo só no computador do dono, fora de qualquer servidor ou repositório público. Nenhum dado da API é vendido, compartilhado com terceiros ou usado para publicidade.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, o token salvo deixa de funcionar.

Serviços do YouTube

A ferramenta usa os Serviços de API do YouTube. Ao usá-la, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Last updated: October 20, 2026. canais-igor is used only by the owner of the YouTube channels Mundo do GTA 6 and Descobrindo Nossa História. With the owner's authorization it uses the YouTube Data API v3 to upload videos to the owner's own channels (youtube.upload) and to read the connected channel's name and ID to confirm the destination (youtube.readonly). It does not access email, contacts, comments, viewer data or anyone else's data. The access token is stored only on the owner's computer.
